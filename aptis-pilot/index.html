문법·어휘와 네 가지 영어 기능을 실제 응답으로 살펴봅니다.

APTIS 유형을 참고한 자체 제작 검토판입니다. 아직 공식 점수나 CEFR을 예측하지 않습니다. 쓰기·말하기는 답안과 녹음을 모아 별도로 평가해야 합니다.
응시 범위

시작 전에

조용한 곳에서 이어폰과 마이크를 준비해 주세요. 사전이나 번역기의 도움 없이 응시해 주세요. 듣기 음원은 각각 최대 두 번, 말하기는 문항별 제한 시간 안에 녹음합니다.

듣기는 검토용 합성 음성입니다. 실제 시험과 음성·분량·운영 방식이 같지는 않습니다. 이 검토판은 과제 이동과 녹음 재시도를 허용하며 재시도 횟수를 기록합니다.

말하기 테스트를 위해 마이크 사용을 허용해 주세요.

‘마이크 3초 확인’을 누른 뒤, 브라우저에서 뜨는 창의 ‘허용’ 또는 ‘이번만 허용’을 선택해 주세요.

녹음한 목소리는 서버로 전송되지 않으며, 직접 재생하고 저장할 수 있습니다.

권한 창에서 마이크를 허용해 주세요. 내장 브라우저에서 작동하지 않으면 현재 주소를 Chrome 또는 Edge에 붙여 넣어 열어 주세요.

답안·녹음은 현재 브라우저 메모리에만 보관합니다. 객관식 채점도 브라우저 안에서 처리하며 답안과 녹음을 서버로 전송하지 않습니다. 화면을 닫기 전에 결과를 다운로드해 주세요. 이메일 발송 기능은 없습니다.

응시 기록

이번 응시를 저장하세요.

아래 ZIP에는 결과 HTML, 답안·진행 기록 JSON, 말하기 녹음이 포함됩니다. 보관하거나 평가자에게 직접 전달할 수 있습니다. 별도 서버 보관이나 자동 이메일 발송은 하지 않습니다.

마이크가 작동하지 않나요?

아래 마이크를 선택하고 ‘마이크 3초 확인’을 눌러 말씀해 주세요. 녹음 후 재생 버튼으로 목소리를 확인하세요.

녹음 중 입력 음량을 표시합니다.

권한 창이 나타나지 않는 경우 Chrome 또는 Edge를 직접 실행하고 아래 주소를 붙여 넣어 주세요.

브라우저가 마이크 접근을 허용해야 입력할 수 있습니다. 앱 내장 브라우저에서는 권한 요청이 처리되지 않을 수 있습니다.
